# 彩绘动物进森林（kid_draw）

一台「主机」打开主题世界并出示房间码；小朋友扫码后只做三件事：**选小鹿 / 老虎 / 狮子 → 大蜡笔涂色 → 按「送进世界」**。创作端不进森林、不换主题、不聊天。画廊是大图，点一下看 3D。

微信 AppID（个人主体）写在 `project.config.json`。无内购、无支付。数据正式走微信云开发；本仓库网页预览用本地 mock，接口在 `web/src/storage/`。

## 网页预览（可先玩）

```bash
cd web
npm install
npm run dev
```

浏览器打开提示的地址（默认 `http://127.0.0.1:43187`）。

1. 点 **打开世界**（家长 / 老师）。
2. 把右侧二维码在新标签打开（等于扫码），会直接进入 **选一只**，不用输房号。
3. 涂色后按超大按钮 **送进世界**，回到主机标签即可看到动物走出来。可切换森林 / 雪原 / 海底。

## 微信开发者工具

1. 安装[微信开发者工具](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)。
2. 导入本仓库根目录（含 `game.js`、`game.json`、`project.config.json`）。
3. 编译类型为小游戏。完整 3D 主题世界以网页预览为准；小游戏包内是同一套双角色 2D 流程。

需要云开发环境 ID 时，放到本机 gitignored 的环境变量，不要写进源码。没有环境 ID 就继续用本地 mock。

## 不要做的事

不要提交 AppSecret、支付密钥、云密钥。不要在孩子界面加设置、聊天或充值。
