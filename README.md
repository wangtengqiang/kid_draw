# 彩绘动物进森林

一台主机打开共享世界；小朋友涂色、把画送进去，送到后可以从成功页 **去看大世界**。可以在手机上涂，也可以打印官方线稿、涂完再拍。MVP **免费**，没有内购、虚拟货币或支付入口。

## 三个用例目录（先看这里）

网页在 `web/src/`，小游戏在 `minigame/`，**两侧同名**：

| 目录 | 用例 | 里面有什么 | 里面没有什么 |
| --- | --- | --- | --- |
| **`child-creation/`** | 孩子屏上涂色 | 选陆地上的小鹿 / 老虎 / 狮子，或海里的小鱼 / 海龟 / 海豚、**自由蜡笔**涂色、导出贴图、**送进世界**、成功页进大世界 | 不换主题、不拍照 |
| **`paper-coloring/`** | 纸上涂色 | 老师下载可打印官方线稿；孩子选一只、拍照 / 选图、对准同一张模板、**送进世界**、成功页进大世界 | 不猜未知动物、没有下载清单当孩子首页 |
| **`world-exhibition/`** | 观展 | 主机主题世界、出示码、画廊大缩略图、**只读** 3D 转台 | 涂色、「送进世界」、拍照 |

不要把这三个用例写回同一个 `app` / `ui` 文件，也不要把文件夹命名成 `upload/`。

旁边的技术层：`storage/`、`sync/`、`cloudfunctions/`（`sendToWorld`、`gallery`、`rooms`，**不进小游戏包**）。纸上拍照和屏上涂色走**同一条** `sendToWorld`。

数据怎么走：选动物 → 涂色或拍照对准 → 云函数 `sendToWorld` → `gallery` / `rooms` → 主机世界。详见 [`docs/architecture.md`](docs/architecture.md)。

## 两种玩法

| 角色 | 入口 | 做什么 |
| --- | --- | --- |
| 观展端 / 主机 | 「打开世界」 | 打开 3D 世界，切换 **森林 / 雪原 / 海底**，出示二维码 + 4 位房号。可暂停收画、清场、结束。同场最多 8 只。 |
| 创作端 · 屏上 | 「开始画画」（网页预览直接进涂色；扫码仍用 `?join=房号`） | 选一只 → **自由蜡笔**涂色 → **送进世界** → **去看大世界**。不用在首页输房号。 |
| 创作端 · 纸上 | 「拍纸上的画」 | 选一只（只限鹿 / 虎 / 狮）→ 大按钮拍照或选图 → 对准官方线稿四角 → **送进世界** → **去看大世界**。 |
| 老师 / 家长 | 「老师打印线稿」 | 下载可打印 PNG。不出现在孩子默认首页当下载列表。 |

看自己画过的立体模型：首页点「我的画」（`world-exhibition` 画廊，只读）。

## 网页预览（推荐用来演示）

需要 Node.js 18+。

```bash
cd web
npm install
npm run dev
```

默认 `http://127.0.0.1:43187`（监听 `0.0.0.0`）。

**屏上涂色（网页预览）**

1. 打开首页，点 **开始画画**。不用扫码、不用带 `?join=`。
2. 选陆地上的小鹿 / 老虎 / 狮子，或海里的小鱼 / 海龟 / 海豚 → **自由蜡笔**涂色（粗细 + 颜色，纸上随便涂）→ **送进世界**。线稿只是样子，不用点满色块。送到后点 **去看大世界** 进主机 3D。
3. 涂色页有大按钮 **重选动物**、**保存草稿**（最多 10 张）和 **我的草稿**。格子满了会让你点一张旧的换掉，不用输房号。首页也可进「我的草稿」。
4. 真机 / 网页扫码：首页点 **扫码进入**。有摄像头就扫主机二维码；云桌面开不了摄像头时，点「选一张二维码图片」（可先在主机点「下载二维码」）。有 `?join=` 时仍进老师的房间。

**主机世界**

点 **打开世界**。大森林能看出远近：高树干、层层树冠、弯岸大海，小路会伸进林子。捏合 / 滚轮可以拉近看动物、拉远看深处。侧栏可换 **森林 / 雪原 / 海底**。陆地动物会自己走路、喝水、休息、坐下（错开节拍，不会一起摆同一个姿势）；海洋动物一直在湾里游，不会走上小路。

**3D 动物**（仅网页）是下载的 **Kenney Cube Pets** glTF，狮 / 鹿 / 虎是真物种、画好的卡通脸、文件里有 `walk`，不是狐狸冒充狮子、也不是狼冒充老虎：

- 狮 / 鹿 / 虎 / 鱼 — [Kenney Cube Pets 2.0](https://kenney.nl/assets/cube-pets)（[CC0](https://creativecommons.org/publicdomain/zero/1.0/)）。zip：https://kenney.nl/media/pages/assets/cube-pets/44e58e945f-1774520254/kenney_cube-pets_1.0.zip
- 海豚 / 海龟 — [Gobkit](https://gobkit.com/api/free) Whale / Seal（CC0）。

孩子涂色乘在皮毛上（默认白色，Kenney 原画脸能看见）。免费包里没有更圆、又是真虎、又能免登录下载的 glTF；取舍见 [`docs/industry-animal-pipeline.md`](docs/industry-animal-pipeline.md)。不要把千图网 PNG 当模型。

**纸上涂色**

1. 标签 A 保持主机世界开着。
2. 标签 B 点「老师打印线稿」，下载小鹿（或「样张：涂好的小鹿」）。
3. 带着 `?join=房号` 点「拍纸上的画」→ 选小鹿 → 选刚下载的图（没有摄像头时用文件选择即可；网页也可点「用刚下载的纸」）→ **送进世界**。
4. 回到 A，那只动物出现在森林里。

房间同步：`BroadcastChannel` + `localStorage`。没有云开发环境 ID 时用 `storage/LocalMockStore`。环境 ID 放本机 gitignored 的变量（见 `web/.env.example`），不要把密钥写进源码。

```bash
cd web
npm test
npm run build
```
